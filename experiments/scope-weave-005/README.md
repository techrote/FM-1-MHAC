# Scope Weave (FM1-003, issue #5)

Original creative exaptation: two ordered unary operators (QUOTE, NEGATE, REQUEST) around one of three leaves (BEACON, RETURN, WAIT); 27 note-key presets. Typed opening and closing motifs and one leaf motif; sixth slot is silent. This is a syntactic toy, not truth evaluation, external action, or human-semantic validation. SEL selects ordered scope, sorted operator comparator, or leaf-only comparator. Sorted mode preserves event count, duration, and exact energy across swapped operands because it emits the same canonical phrase. Leaf mode is not energy matched. Key 3 is QUOTE(NEGATE(BEACON)); key 9 NEGATE(QUOTE(BEACON)) using zero-based key indices. Knob 1 selects tempo (0..26), PLAY toggles, HOME stops new events; an existing envelope completes within 2048 frames (46.44 ms). Boot silent. 44.1 kHz additive stereo int32 Q15, caller supplies zeroed buffer/headroom. No heap, input audio, network, storage, MIDI, or flash operations.
